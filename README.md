# Laporan Logbook Edu

A web-based employee activity reporting and daily logbook management system for organizational use.

## Overview

Laporan Logbook Edu is a web application designed to digitize employee daily activity reporting and simplify the process of collecting, managing, and reviewing employee logbooks.

The system provides different logbook forms based on employee divisions and a centralized manager section for reviewing and recapitulating submitted reports.

## Features

- Employee daily activity logbook
- Division-based logbook forms
- IT activity reporting
- Finance activity reporting
- Staff activity reporting
- Teaching team activity reporting
- Manager dashboard
- Employee activity recap
- Report filtering by division
- File upload for logbook reports
- Activity notification system
- Digital report management

## Divisions

The system supports several employee divisions:

- IT
- Finance
- Staff
- Teaching Team

Each division has its own logbook form according to its responsibilities and daily activities.

## Manager & Recap

The manager section provides centralized access to employee reports, including:

- All Reports
- IT Recap
- Finance Recap
- Staff Recap
- Teaching Team Recap

This allows managers to monitor employee activities and review submitted reports efficiently.
